FROM DIGITAL LOGIC TO AI HARDWARE

TinyRISC-AI Lab

A visual, beginner-friendly CPU simulator project. We build hardware blocks one by one, connect them into a Mini CPU, then add a custom AI dot-product accelerator.

CPU-only PC
No FPGA required

What did we build?

First we describe hardware in SystemVerilog. Then Icarus Verilog simulates that hardware. Testbenches verify that each block behaves correctly. Finally, Python trains a tiny ML model and we compare ordinary CPU-style arithmetic with a dedicated simulated AI accelerator.

LEARNING PATH

How the CPU is built

Each card is a mini-project. The later CPU reuses these same ideas as building blocks.

01

AND Gate

Our first logic circuit. Output is 1 only when both inputs are 1.

a & b → y
02

MUX

A selector. It chooses which input is allowed to continue.

sel ? b : a
03

Register

A tiny memory cell. It updates its stored value on a clock edge.

clock → store d
04

Counter / PC

A register that advances. In a CPU it becomes the Program Counter.

PC → PC + 1
05

ALU

The calculator of the CPU: ADD, SUB, AND, OR and XOR.

A op B → result
06

Register File

A small bank of registers that holds operands and results.

R1 + R2 → R3
07

Decoder

Translates an instruction into control signals that tell the CPU what to do.

instruction → controls
08

Mini CPU

Now the blocks work together to fetch, decode and execute instructions.

fetch → decode → execute
09

AI Accelerator

A dedicated int8 dot-product block for ML-style multiply-and-accumulate work.

Σ xᵢwᵢ
