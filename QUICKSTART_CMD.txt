TinyRISC-AI - Docker Compose quick start (Windows CMD)

1) Make sure Docker Desktop is running.

2) Open CMD:
cd C:\Users\YOUR_USER\Documents\GitHub\tiny-risc-ai

3) Build + run:
docker compose up --build

4) Open browser:
http://localhost:8080

5) Run all hardware tests in another CMD:
docker compose run --rm tiny-risc-ai sh scripts/run_sv_tests.sh

6) Run AI training + benchmark:
docker compose run --rm tiny-risc-ai sh scripts/run_ai_demo.sh

7) Stop:
docker compose down
