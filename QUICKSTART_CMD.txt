TinyRISC-AI — Windows CMD quick start

1. Start Docker Desktop.
2. Open CMD in the repo folder.
3. Build and start:

   docker compose up --build

4. Open:

   http://localhost:8080

5. Press RUN ALL.

The flow is:
scikit-learn training -> export model -> compile TinyRISC instructions -> load Instruction Memory -> execute inference on TinyRISC CPU.

Decision Tree and Random Forest control flow is executed inside TinyRISC with BEQ/BNE/JUMP.

CLI full run:
   docker compose run --rm tiny-risc-ai sh scripts/run_all.sh

CPU tests:
   docker compose run --rm tiny-risc-ai sh scripts/run_sv_tests.sh

Stop:
   docker compose down
