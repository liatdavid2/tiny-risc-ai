TinyRISC-AI - Windows CMD quick start

1) Start Docker Desktop.

2) Open CMD in the repository folder:
   cd C:\Users\YOUR_USER\Documents\GitHub\tiny-risc-ai

3) Build and start the custom one-screen UI:
   docker compose up --build

4) Open:
   http://localhost:8080

The UI lets you:
- test the CPU building blocks
- train 4 sklearn models on the host CPU inside Docker
- choose Logistic Regression / Decision Tree / Random Forest / MLP
- export the learned parameters
- run inference in generated SystemVerilog with Icarus Verilog

Run all hardware tests + all four model inference demos from CMD:
   docker compose run --rm tiny-risc-ai sh scripts/run_all.sh

Run only the ML hardware inference demos:
   docker compose run --rm tiny-risc-ai sh scripts/run_models.sh

Stop:
   docker compose down
