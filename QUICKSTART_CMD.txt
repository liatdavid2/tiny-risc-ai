TinyRISC-AI — Windows CMD quick start

1) Open Docker Desktop.

2) In CMD, enter the repository:
   cd C:\Users\YOUR_USER\Documents\GitHub\tiny-risc-ai

3) Build + start:
   docker compose up --build

4) Open:
   http://localhost:8080

5) In the UI:
   - Dataset: Breast Cancer (binary) OR Iris (3-class)
   - Click 1. TRAIN ALL MODELS
   - Set Max / class
   - Click 2. RUN BATCH INFERENCE

No synthetic dataset is used.

CLI examples:
   docker compose run --rm tiny-risc-ai python python/train_models.py --dataset breast_cancer
   docker compose run --rm tiny-risc-ai python python/train_models.py --dataset iris
   docker compose run --rm tiny-risc-ai python python/run_batch_benchmark.py --max-per-class 25

Stop:
   docker compose down
